# SaltGuard MVP 1.0.6

Chạy `start_windows.bat`, mở `http://127.0.0.1:8000`.

- **Cài đặt nâng cao** trong tab Cài đặt: nhập PIN demo `1111` để vào Chuyên môn / Phòng mô phỏng.
- PIN có thể đổi bằng `SALTGUARD_ADVANCED_PIN` (4 chữ số) trước khi chạy backend.
- Thông báo đang diễn ra và thông báo đã qua được lưu riêng vào `data/saltguard.db`.
- Trang chủ hiển thị thời gian tưới ưu tiên và hoạt động gần đây.
- Tham khảo `../README_1_0_6.md` về giới hạn bảo mật demo và cách nâng cấp dữ liệu.
